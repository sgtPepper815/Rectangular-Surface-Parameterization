# Mesh Processing & Surface Parameterization

*C++ · OpenGL · Computational Geometry*

An educational implementation of surface parameterization techniques, exploring mesh topology, local coordinate systems, and the mapping of 3D surfaces into 2D parameter domains.

## Implemented Features

- [x] Per-triangle normal computation
- [x] Local orthonormal tangent frame construction
- [x] Visualization of normals and tangent vectors
- [x] Local 3D-to-2D triangle parameterization
- [x] Edge-to-triangle connectivity and adjacency detection
- [x] Boundary and interior edge classification
